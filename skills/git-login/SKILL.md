# Git Login

브라우저(Chromium) 세션에 GitHub 로그인을 만든다.

## 절차

1. **상태 확인**: 브라우저 작업으로 `github.com`에 접속한다. 우상단에 아바타가
   보이면 이미 로그인된 것 — 사용자명을 확인하고 종료한다.
2. **로그인 페이지**: 미로그인이면 `github.com/login`으로 이동한다.
3. **방식 선택**: 사용자가 지정한 방식(비밀번호 / Continue with Google)을 따른다.
   지정이 없으면 비밀번호 방식을 기본으로 한다.
   - Continue with Google: Google 계정 선택 화면에서 계정을 선택한다.
     계정이 목록에 없으면 이메일 입력 → 비밀번호 단계로 넘어간다.
4. **자격 증명**: `credentials.request_login` 보안 카드로 수집한다.
   `page_url`은 실제 로그인 페이지(`github.com/login` 또는 `accounts.google.com`)로.
   **비밀번호를 채팅 평문으로 요구하지 않는다.** 카드 입력은 Secure Vault로 가고
   에이전트는 볼 수 없다.
5. **2FA/OTP**: 인증 코드가 필요하면 연결된 이메일/메시지에서 보호된 코드 조회를
   먼저 시도한다. 안 되면 사용자에게 직접 입력을 요청하거나 브라우저 takeover를
   제안한다.
6. **검증**: 아바타와 사용자명이 보이는지로 로그인 성공을 확인하고, 로그인된
   사용자명을 보고한다.

## 주의

- 비밀번호·OTP를 채팅으로 받지 않는다.
- CAPTCHA가 나타나면 저장된 설정을 확인하고, 없으면 사용자에게 물은 뒤 진행한다.
- 한 번 만든 로그인 세션은 브라우저에 유지되므로 다음 작업에서 재사용한다.
- 관련 스킬: `git-create`(저장소 생성), `git-upload`(push).
